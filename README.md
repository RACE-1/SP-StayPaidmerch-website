# STAYPAID MERCH — High-Velocity Street Luxury

A high-fidelity, cinematic "1:1 Pixel Perfect" digital instrument and e-commerce experience for StayPaid Merch.

## Features
- **Design System:** Midnight Luxe (Obsidian `#0D0D12`, Champagne `#C9A84C`, Ivory `#FAF8F5`, Slate `#2A2A35`).
- **Visual Texture:** Global SVG `<feTurbulence>` noise texture overlay at 0.05 opacity.
- **Micro-Interactions:** Magnetic button dynamics with sliding color-fill transitions.
- **Floating Morphing Navbar:** Auto-morphing pill header with real-time cart trigger.
- **Opening Shot (Hero):** 100dvh full-bleed editorial imagery, heavy gradient overlay, high-contrast typography, and staggered GSAP entrance.
- **Interactive Functional Micro-UIs:**
  - *Silhouette Diagnostic Shuffler* (Card 1)
  - *Direct Pricing Telemetry Typewriter* (Card 2)
  - *1-Click Protocol Scheduler* (Card 3)
- **Drop Catalog:** Interactive product grid, sizing matrix, live cart drawer, and order simulation modal.
- **Sticky Stacking Protocol Archive:** 3 full-screen pinned stacking cards with GSAP ScrollTrigger.
- **System Operational Indicator:** Pulsing status signal with real-time telemetry.

## Quick Start

### 1. Instant Preview (No install needed)
Open `index-standalone.html` in any modern web browser.

### 2. Local Development (Vite + React)
```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

### 3. Production Build
```bash
npm run build
```
